Privacy Policy

Periodic Table Poker · Last updated: February 2025

Overview

Periodic Table Poker is an educational card game. We aim to collect minimal data and keep gameplay local.

Data We Collect

Gameplay: The game runs entirely on your device. Card deals, scores, and game state are not sent to our servers.

Firebase: The app may use Firebase for configuration. Firebase's standard API keys are embedded in the app; these identify the project and are not secret. No analytics or user data is collected unless you explicitly sign in.

GitHub Issues: If you use "Submit to Hierarchy," you optionally enter text (e.g. your name) that is sent to GitHub when you open a new issue. This is done by your browser opening GitHub's website; we do not receive or store this data.

Third Parties

GitHub: When you submit to the hierarchy, you open github.com. GitHub's privacy policy applies to data you provide there.

Firebase/Google: Used for hosting and optional services. See Firebase Privacy.

Children

This is an educational game suitable for all ages. We do not knowingly collect personal information from children.

Contact

Questions? Open an issue at GitHub Issues.
